# E-Library

A simple E-Library web application built with TypeScript, Vite, HTML, and CSS.

The project demonstrates Object-Oriented Programming (OOP) concepts such as classes, inheritance, encapsulation, and polymorphism.

## Features

- Display books as cards.
- Search books by title or author.
- Filter books by category.
- Toggle book availability.

## Technologies

- HTML5
- CSS3
- TypeScript
- Vite
- JavaScript DOM API
- Object-Oriented Programming
